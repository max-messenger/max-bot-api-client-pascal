Create a bot in MAX, then set its token at run time: the `Token` property of the `DTMaxLongPollBot` component is declared `stored False` (td-026), so a value typed into the Object Inspector is never written to the form file and never reaches the running program. Assign `DTLongPolBot1.Token` from your own code before `StartReceiver` runs (for example, in the form's `OnCreate` handler). See the security note in the repository `README.md`.
