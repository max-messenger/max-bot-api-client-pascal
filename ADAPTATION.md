# О проекте / About this project

Этот проект — адаптация библиотеки **fp-telegram** (FreePascal-клиент
Telegram Bot API) под мессенджер **MAX** (`https://dev.max.ru`,
API `https://platform-api2.max.ru`).

Оригинал: `https://github.com/Al-Muhandis/fp-telegram`
(авторы оригинала — см. `LICENSE` и `contributors.txt`; лицензия MIT
сохранена без изменений).

Дата адаптации: 2026-10-29.

---

# In English

This project is an adaptation of the **fp-telegram** library (a
FreePascal Telegram Bot API client) for the **MAX** messenger
(`https://dev.max.ru`, API `https://platform-api2.max.ru`).

Original: `https://github.com/Al-Muhandis/fp-telegram`
(original authors — see `LICENSE` and `contributors.txt`; the MIT
license is kept unchanged).

Adaptation date: 2026-10-29.
